BBX80 for MSX
=============

In this folder are the sources for the MSX home computer edition of BBX80.


Changelog:
----------
V1.1:
- added commands:
  *drive X:   set default drive to X:
  *end        reset screen and end program
  *list       clears screen before list
  *turbo NN   set turbo mode to NN (00,01,02,80,81,82)
- added custom MSX-DOS error handler
- added MSX-DOS 1 support for default drive
- smart text/graphics mode for faster text scrolling
V1.0: 
- initial release
